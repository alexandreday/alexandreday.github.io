From Clicks to Intent: Cross-Platform Session Embeddings with LLM-Distilled Taxonomy for Financial Services Recommendations

Dianjing Fan, Yao Li, Kyaw Hpone Myint, Dwipam Katariya, Alexandre G.R. Day, Pranab Mohanty, Giri Iyengar

Capital One

arXiv PDF
TL;DR

We turn anonymous pre-login web clickstreams into two complementary outputs — a self-supervised session embedding for quantitative recommendation tasks, and LLM-distilled intent labels for interpretable understanding at low latency — and show both pay off on real financial-services personalization tasks.

The problem

In financial services, how people behave before and after they log in is strikingly different. Pre-login web visitors are usually exploring — comparing products and shopping around — while logged-in app users are mostly servicing an existing account. That mismatch, combined with the difficulty of matching an anonymous web session to an authenticated mobile account (cross-channel entity resolution), means the rich intent signal in web clickstreams is often left on the table when it comes to in-app personalization.

Existing ways of capturing web-based intent tend to be ad-hoc and narrow. They lack the flexibility to serve both the quantitative downstream tasks (ranking, conversion prediction) and the qualitative, human-readable understanding that an enterprise setting demands.

The approach

We propose a single, scalable framework that transforms raw web clickstreams into two outputs at once. A self-supervised Transformer fuses multi-modal clickstream events into a compact session embedding that feeds quantitative models. In parallel, an LLM-based taxonomy generation and distillation pipeline produces interpretable intent labels — useful both for analysis and for stakeholders who need to know why a recommendation was made. Crucially, the distilled labels run at ultra-low latency, so the interpretability comes cheap in production.

Results

We evaluate the framework on two real production tasks — mobile homepage tile ranking and user conversion prediction:

+1.88%
macro Recall@1 on tile ranking
−13.38%
Log Loss on tile ranking
+4.3%
micro F1 vs. LLM labels on conversion
−7%
drop for ultra-low-latency distilled labels

On mobile homepage tile ranking, the session embedding improves macro Recall@1 by 1.88% and reduces Log Loss by 13.38% over production baselines. On user conversion prediction, the embedding outperforms the LLM intent labels by 4.3% on micro F1, while the distillation layer still delivers interpretable labels with only a 7% performance drop.

Why it matters

Self-supervised clickstream representations and LLM-distilled taxonomies are not competing approaches — used together, one system can serve both the quantitative recommendation tasks and the qualitative, human-readable understanding that real enterprise deployments require. That combination is what makes pre-login web intent finally usable for post-authentication personalization.
